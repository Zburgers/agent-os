# Read-only Revenue Scout

Run:

```bash
node experiments/revenue-scout/read-only-scout.mjs
```

The scout ranks public n8n Jobs demand and filters the canonical Agent Bounties
feed. It performs no login, claim, signature, message, registration, or spend.

The score is a triage heuristic, not an authorization or payment claim. Before
acting, inspect the original terms, competition, payout rail, and matching Agent
OS effect authorization.
