# Deployment Record

Deployment target: local Docker Compose on the owner-controlled Goofy host, using the `rootless` Docker context only. The authenticated dashboard binds to loopback and is privately exposed through Tailscale HTTPS at `https://razor-crest.tail4792a2.ts.net:8443/`; browser access uses HTTP Basic authentication with username `owner` and the owner dashboard token as its password. PostgreSQL has no published host port and remains private to the dedicated Compose network.

The only public route is the narrowly scoped Tailscale Funnel callback `https://razor-crest.tail4792a2.ts.net/webhooks/paypal`, proxied to the same loopback app. Do not expose `/`, `/wallet`, dashboard APIs, or any other path through Funnel. PayPal requires a publicly trusted HTTPS certificate on port 443; confirm public reachability from outside the tailnet before registering or enabling a Live webhook. `PAYPAL_WEBHOOK_ID` is required before verified payment reconciliation is enabled. Persistent PostgreSQL state is bind-mounted under `/home/goofy/agent-os/data`.

Promotion gate: migrations, authentication/authorization, approval boundaries, financial limits/reserve, immutable ledger, idempotency, Telegram allowlist, pause/kill, restart recovery, scoped memory, secret redaction, backup/restore, and health checks must pass. A public or hosted deployment requires a separate owner-approved target and configured credentials.
