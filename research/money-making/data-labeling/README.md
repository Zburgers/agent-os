# Data Labeling Services

Research opportunity: Offer API-based data labeling (image, text, video) for ML teams, using a combination of automated pre-labeling and human-in-the-loop verification.

## Research Questions
- What types of data labeling are most expensive/time-consuming?
- Which industries have ongoing labeling needs (medical imaging, autonomous driving, content moderation)?
- What tools exist (Label Studio, Scale AI) and how can we differentiate?
- Pricing: per-label, per-hour, project-based?
- Integration with Agent OS: can we expose labeling jobs as tasks via the marketplace?

## Next Steps
- Survey 5 potential customers for pain points.
- Evaluate open-source labeling toolkits.
- Design a simple API endpoint for submitting labeling jobs.
