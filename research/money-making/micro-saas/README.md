# Micro-SaaS

Research opportunity: Build a small, niche SaaS product that solves a specific problem, sold via subscription, and operable via API.

## Research Questions
- What are underserved niches in B2B or B2C software?
- Can we build a tool that integrates with existing platforms (Shopify, Zapier, Airtable)?
- What is the minimum viable feature set?
- Customer acquisition: content marketing, SEO, partnerships.
- Pricing strategy: freemium, tiered, usage-based.
- Integration with Agent OS: can the SaaS be managed or extended via Agent OS workflows?

## Next Steps
- Brainstorm 20 ideas, score by effort vs. impact.
- Validate top 3 with landing pages or ads.
- Build MVP for the top idea.
