# Money-Making Research for Agent OS

This directory contains research documents for various income-generating niches that are compatible with the Agent OS (preferring API-based, automatable approaches).

Each subdirectory focuses on a specific niche or track, designed to be assigned to a single agent for deep work without overlap.

## Niches
- API Wrappers
- Data Labeling
- Micro-SaaS
- Affiliate API
- AI Services
- Automation Workflows

Each niche directory contains a starter README with research questions and a place to log findings.
