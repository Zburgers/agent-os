# Automation Workflows (Zapier/Make.com alternatives)

Research opportunity: Build a low-code workflow automation platform with a focus on developer-friendly APIs and extensibility.

## Research Questions
- What are the limitations of Zapier/Make.com for developers (cost, flexibility, custom code)?
- Can we offer a simpler, cheaper alternative focused on specific triggers/actions (e.g., webhooks, DB, email)?
- What is the core engine (temporal, airflow, custom)?
- How to handle auth, secrets, and scaling?
- Monetization: per-run, subscription, or enterprise.
- Integration with Agent OS: can workflows be triggered by Agent OS events or vice versa?

## Next Steps
- Map out common workflow patterns (lead enrichment, content publishing, data sync).
- Prototype a simple workflow engine with a few integrations.
- Test with a small group of makers.
